# AKINTI — Rain Line

AKINTI is an English-language showcase for a modular urban rainwear concept. It
includes an interactive visor, five gear close-ups tied to page scrolling, a
drag-to-compare portrait, a rain simulation, and a customizable kit.

## Run locally

Open `index.html` in a web browser. All images, fonts, styles, and scripts are
included. No installation or build is required.

Kit selections and interest-list entries are stored in the current browser.
The rain chamber shows simulated conditions and styling suggestions.
